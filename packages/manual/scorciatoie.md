# Scorciatoie da tastiera

## Testo

| Tasti | Azione |
|---|---|
| `Ctrl+B` | Grassetto |
| `Ctrl+I` | Corsivo |
| `Ctrl+U` | Sottolineato |
| `Ctrl+K` | Link |
| `Ctrl+]` | Aumenta rientro |
| `Ctrl+[` | Riduci rientro |
| `Ctrl+Z` | Annulla |
| `Ctrl+Y` | Ripristina |
| `Ctrl`+clic | Apre un link o va al diagramma del riferimento |

## Mosse

| Tasti | Azione |
|---|---|
| `←` / `→` | Mossa precedente / successiva |
| `↑` / `↓` | Variante precedente / successiva |
| `Home` | Inizio |
| `Fine` | Fine della linea |
| `Q` `R` `B` `N` | Scelta del pezzo in promozione |
| `Esc` | Annulla la promozione |
| Clic destro sulla scacchiera | Freccia (trascinando), cerchio, X al secondo clic sulla stessa casa: vedi [Frecce, cerchi e X](./scacchiera#frecce-cerchi-e-x) |
| `Maiusc` o `Ctrl` + clic destro | Come sopra, in grigio nel libro |
| `Ctrl+V` | Incolla l'albero copiato o tagliato |

## Diagrammi e copertina

| Tasti | Azione |
|---|---|
| `Invio` | Conferma la didascalia |
| `Maiusc+Invio` | A capo nella didascalia |
| `Canc` | Elimina il testo selezionato in copertina |

## Generali

| Tasti | Azione |
|---|---|
| `F1` | Apre il manuale (app desktop) |
| `Esc` | Chiude finestre, menu ed editor scacchiera |

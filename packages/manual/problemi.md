# Problemi frequenti

## Non riesco a modificare il libro

Il libro è in sola lettura. Usa l'interruttore nell'intestazione: deve indicare **Modifica attiva**.

## Le mosse sulla scacchiera non entrano nel libro

La barra di stato indica **Posizione libera**. Clicca una mossa di un albero per attivarlo, oppure crea un nuovo albero.

## Non riesco a cambiare la posizione iniziale di un albero

La posizione è fissata quando l'albero ha già delle mosse. Crea un nuovo albero da quella posizione.

## L'intestazione dice «Nessun file associato»

Il libro è solo nella copia interna. Usa **Salva Lavoro** per scegliere un file e attivare il salvataggio automatico.

## L'intestazione dice «salvataggio automatico sospeso»

Il file è stato modificato da un altro programma. Usa **Salva Lavoro** e scegli se sovrascrivere o salvare con un altro nome. Vedi [Modifiche esterne](./salvataggio#modifiche-esterne).

## Sul web compare «Spazio del browser esaurito»

Il browser non riesce più a conservare la copia automatica. Usa subito **Salva Lavoro** per scaricare il file.

## Un riferimento a un diagramma mostra «?»

Il diagramma collegato è stato eliminato. Cancella il riferimento o inseriscine uno nuovo.

## Il motore non parte o viene rifiutato

Il file scelto deve essere un programma UCI per il tuo computer. Controlla il messaggio nel pannello **Motore** e, se serve, scegli di nuovo l'eseguibile.

## Un blocco dice «Albero non trovato»

Prova ad annullare l'ultima operazione, oppure elimina il blocco.

## Windows blocca l'installazione

L'app non è firmata. Su SmartScreen scegli **Ulteriori informazioni** e poi **Esegui comunque**.
